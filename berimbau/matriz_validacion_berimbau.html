Club Berimbau · Dashboard de Cobranza

Guía de pruebas para el equipo del Club

Este documento sirve para revisar, punto por punto, que el dashboard haga lo que se acordó. Cada punto te dice qué se prueba, cómo hacerlo paso a paso y qué debe pasar. Cuando el resultado sea el esperado, marca la casilla; si algo no cuadra, escríbelo en el espacio de anotaciones.

No se necesita ningún conocimiento técnico: todo se hace desde el dashboard y desde el archivo de Excel que se descarga con el botón Exportar.

Antes de empezar, tres cosas:
1. La información se actualiza desde el Sistema cada hora, así que es normal que las cifras cambien de una sesión a otra. Lo importante es que sean coherentes entre sí.
2. El Modo Prueba está encendido: ningún socio real recibe correos ni mensajes durante estas pruebas.
3. Al terminar, usa el botón Exportar a PDF para guardar tus anotaciones. Si cierras la pestaña antes de exportar, lo escrito se pierde.

Qué se prueba

Cómo hacerlo

C1Socio de pago mensual
Qué se prueba
Desde cuándo empieza a contar el atraso de un socio mensual.
Cómo hacerlo

C2Socio de pago trimestral
Qué se prueba
La regla especial de los trimestrales.
Cómo hacerlo
